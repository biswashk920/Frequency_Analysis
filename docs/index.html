Flood frequency analysis

Estimate how big a flood or heavy rainstorm could be, and how often it is likely to happen. Paste your yearly highest values (one per year), and the tool shows the expected size of the 2, 5, 10, 25, 50, 100, 200 and 500-year events, using four standard statistical methods: Gumbel, GEV, Log Normal and Log Pearson III. Everything runs in your browser, and your data is never uploaded.

Use one value per year: the highest flow, or the highest rainfall for one fixed duration such as 24 hours. Confidence level sets how wide the uncertainty range is (higher means wider). Simulations are repeated test runs used to estimate that range: more is smoother but slower, and 1000 is fine.

Return period estimates

The large number is the best estimate. The smaller line beneath it is the lower and upper limit of the uncertainty range. The 100-year row is highlighted.

Frequency curves

Gumbel and GEV use L-moments (Hosking 1990); Log Normal uses the moments of ln x; Log Pearson III uses the moments of log10 x with sample skew and the Wilson-Hilferty frequency factor. Bands are 2.5–97.5 percentile (for 95%) parametric bootstrap. The Python package in this repository uses exact SciPy quantiles for Log Pearson III, so values can differ slightly. Weibull plotting positions. Long return periods from short records are extrapolation.
